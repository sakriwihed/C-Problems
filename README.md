# C Programming Problems

Problems I solved during my Computer Science studies at **ESPRIT (Tunisia)** and **TU Braunschweig (Germany)**.
They cover: structs, pointers, dynamic memory, strings, arrays, sorting/searching and data structures.

| Problem | Description | Concepts |
|---|---|---|
| [AidDistribution](AidDistribution) | Manages a stock of humanitarian aid and assigns it to families | structs, arrays, multi-file project |
| [BookManagement](BookManagement) | Stores books with authors and publication dates | nested structs |
| [CakeShop](CakeShop) | Manages cakes, recipes and daily sales | structs, 2D arrays, multi-file project |
| [BinarySearch](BinarySearch) | Sorts arrays and searches values with dichotomous search | sorting, binary search |
| [PatientManagement](PatientManagement) | Patient list with statistics; pushes patients onto a stack by status (exam project) | linked structures, stack |
| [LinkedList](LinkedList) | Singly linked list with append and pop | `malloc`, pointers, dynamic memory |
| [MachineFailures](MachineFailures) | Tracks machines and their failures, repaired vs. not repaired | structs, pointers |
| [Matrix](Matrix) | Reads and displays matrices, finds the max of each row | 2D arrays |
| [StringConcatenation](StringConcatenation) | Concatenates strings with and without `string.h` | strings |
| [WordAnalysis](WordAnalysis) | Splits a sentence into words, counts vowels, rebuilds sentences | strings, 2D char arrays |
| [Palindrome](Palindrome) | Checks whether a string is a palindrome | strings |
| [ExpenseReports](ExpenseReports) | Manages members, expense reports and reimbursement limits | structs, search |
| [PriorityStack](PriorityStack) | Stack of folders that can be sorted by priority | stack, linked structures |
| [Students](Students) | Reads and swaps student records using pointers | structs, pointers |
| [CarRental](CarRental) | Stores rental cars and looks up their details | arrays of structs |
| [Substrings](Substrings) | Checks whether a string is a substring of another | strings |


## How to run

```bash
gcc *.c -o program
./program
```
