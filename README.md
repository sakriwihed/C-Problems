# C Programming Problems

Problems I solved during my Computer Science studies at **ESPRIT (Tunisia)** and **TU Braunschweig (Germany)**.
They cover the fundamentals: structs, pointers, dynamic memory, strings, arrays, sorting/searching and data structures.

## C

| Problem | Description | Concepts |
|---|---|---|
| [AidDistribution](C/AidDistribution) | Manages a stock of humanitarian aid and assigns it to families | structs, arrays, multi-file project |
| [BookManagement](C/BookManagement) | Stores books with authors and publication dates | nested structs |
| [CakeShop](C/CakeShop) | Manages cakes, recipes and daily sales | structs, 2D arrays, multi-file project |
| [BinarySearch](C/BinarySearch) | Sorts arrays and searches values with dichotomous search | sorting, binary search |
| [PatientManagement](C/PatientManagement) | Patient list with statistics; pushes patients onto a stack by status (exam project) | linked structures, stack |
| [LinkedList](C/LinkedList) | Singly linked list with append and pop | `malloc`, pointers, dynamic memory |
| [MachineFailures](C/MachineFailures) | Tracks machines and their failures, repaired vs. not repaired | structs, pointers |
| [Matrix](C/Matrix) | Reads and displays matrices, finds the max of each row | 2D arrays |
| [StringConcatenation](C/StringConcatenation) | Concatenates strings with and without `string.h` | strings |
| [WordAnalysis](C/WordAnalysis) | Splits a sentence into words, counts vowels, rebuilds sentences | strings, 2D char arrays |
| [Palindrome](C/Palindrome) | Checks whether a string is a palindrome | strings |
| [ExpenseReports](C/ExpenseReports) | Manages members, expense reports and reimbursement limits | structs, search |
| [PriorityStack](C/PriorityStack) | Stack of folders that can be sorted by priority | stack, linked structures |
| [Students](C/Students) | Reads and swaps student records using pointers | structs, pointers |
| [CarRental](C/CarRental) | Stores rental cars and looks up their details | arrays of structs |
| [Substrings](C/Substrings) | Checks whether a string is a substring of another | strings |


## How to run

**C**
```bash
gcc *.c -o program
./program
```
